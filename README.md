# Mystic Woods

## [▶ Play Mystic Woods in your browser](https://stevecastaneda.github.io/mystic-woods-play/)

A top-down forest adventure in the spirit of Zelda: A Link to the Past. Explore the woods, battle monsters, craft gear, and play Story Mode or Endless Wilds, alone or with a friend. It plays with a keyboard, a controller, or touch on an iPad turned sideways.

This repository holds the game's published browser build. It updates each time a new version ships, and the game's What's new button lists the latest changes.
